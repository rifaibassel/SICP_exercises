```scheme
(define (sum-over-a-range sum-proc next-proc a b)
  (if (> a b)
      0
      (+ (sum-proc a) (sum-over-a-range sum-proc next-proc (next-proc a) b)))
  )

(define (increment x)
  (+ x 1)
  )

(define (simpson-integral f a b n)
  (define (h)
    (/ (- b a) n)
    )
  (define (y k)
    (cond ((or (= k 0) (= k n)) (f (+ a (* k (h))))) 
          ((even? k) (* 2 (f (+ a (* k (h)))))) 
          (else (* 4 (f (+ a (* k (h))))))
          )
   )
  
  (* (/ (h) 3) (sum-over-a-range y increment 0 n))
)
```

The difference between the true integral and the integral generated by the simpson-integral is smaller than the difference between the true integral and the integral generated by the integral procedure, thus the simpson-integral procedure provides a more accurate result
